# 保安林凡例作図アプリ 操作マニュアル

このマニュアルは、保安林凡例作図アプリの基本的な使い方を解説するものです。

---

## 1. データの読み込み
まずは、ベースとなる図面データをアプリに読み込みます。

1. 画面上部の **「KML/XML等読込」** ボタンをクリックします。
2. 対象となるファイルを選択します。
   - **KMLファイル** (QGIS等から出力したポリゴンデータ)
   - **XMLファイル** (法務省SIMA座標データ等)
   - **JSONファイル** (過去に本アプリで保存した作業データ)

## 2. 背景地図・TIFF画像の表示
作図の補助として、背景に地図や画像を表示できます。

- **地理院地図の表示:** 画面左上の「地球儀アイコン」をクリックすると、地理院地図が表示されます。隣のプルダウンから「淡色地図」「標準地図」「航空写真」を切り替えることができます。
- **TIFF図面の読み込み:** 画面右側のパネルから「TIF背景読込」ボタンを押し、図面のTIFFファイル（とTFWファイルが含まれるZIP）を読み込むと、正しい座標位置に重なって表示されます。
- **背景画像の管理:** 左上の「歯車アイコン」から、読み込んだTIFF画像を個別に削除したり管理することができます。カラー写真か白黒図面かを自動判別し、作図レイヤの色（見やすさ）が自動で最適化されます。

## 3. 凡例（スタイル）の一括適用と編集
読み込んだポリゴン（図形）に対して、保安林の種別に応じた色や網掛け模様を一括で設定します。

1. 画面右側のパネルから、適用したい凡例（例：「土砂流出防備」「水源涵養」など）を選びます。
2. 画面上のポリゴンをクリックして選択状態（太枠）にします。複数選択やドラッグでの範囲選択も可能です。
3. パネルの **「選択図形に適用」** ボタンを押すと、一括で色と模様が適用されます。

## 4. 各種モードの使い方（ツールパネル）
画面右側のツールパネル上部から、操作モードを切り替えて細かい編集を行います。

### 👆 選択モード
- ポリゴンをクリックして選択し、個別に凡例スタイルを変更できます。
- **「メガネ（一部解除）」** や **「地目（枠のみ）」** などの特殊なスタイル変更も可能です。

### ✂️ 作図モード
- ポリゴンを直線で分割・切断するためのモードです。
- 地図上をクリックして線を引くことで、図形を分割できます。既存の頂点にマウスを近づけると、自動でピタッとくっつく「スナップ機能」が働きます。
- 線の引き終わりは `Enter` キー、またはダブルクリックで確定します。

### 🅰️ 文字追加モード
- 地図上に文字や記号を配置します。
- 右パネルで文字の種類（字・一般、地番、林班、小班など）と内容を入力し、地図上の配置したい場所をクリックします。

### 🔄 装飾調整モード
- 配置した文字や記号の位置を微調整するモードです。
- 文字をドラッグ＆ドロップで好きな位置に動かすことができます。
- 不要になった文字は、クリックして選択した状態にし、パネル内の「選択中オブジェクトを削除」ボタンで消すことができます。

## 5. データの保存と出力
作業が完了したら、CAD用のデータや、再編集用のデータとして保存します。

- **DXF出力:** 画面上部の **「DXF出力」** ボタンを押すと、AutoCAD等のCADソフトで読み込めるDXF形式でダウンロードされます。色や網掛け模様、配置した文字もすべてCAD上で再現されます。
- **作業状況保存:** 画面上部の **「作業状況保存」** ボタンを押すと、現在の状態がまるごとJSON形式でダウンロードされます。（読み込んだTIFF画像も含まれます）。
次回、このJSONファイルを「KML/XML等読込」から読み込むことで、100%同じ状態から作業を再開できます。
